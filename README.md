# Doce Celebra — specs do projeto

Bolos caseiros por encomenda, entrega por delivery

| Arquivo | O que guarda |
| --- | --- |
| `descoberta.md` | Público, objetivo, ação principal e persona |
| `design.md` | Personalidade, cores, tipografia e tom |
| `tokens.css` | As mesmas decisões em variáveis CSS |
| `arquitetura.md` | Mapa, wireframe, páginas e fluxo |
| `componentes.md` | O que é global e o que é de página |
| `tecnologia.md` | Estrutura (Astro), hospedagem e limites do MVP |
| `roteiro-teste.md` | As tarefas do teste de usabilidade |

## Ordem de leitura
`descoberta.md` → `design.md` + `tokens.css` → `arquitetura.md` → `componentes.md` → `tecnologia.md` → `roteiro-teste.md`.

## Próximo passo
1. Abra o repositório do projeto no OpenCode.
2. Peça em **Plan Mode**: "Leia `descoberta.md`, `design.md`, `tokens.css`, `arquitetura.md`, `componentes.md`, `tecnologia.md` e `roteiro-teste.md` antes de alterar qualquer arquivo."
3. Construa uma página por vez. A ação principal é: **Pedir pelo WhatsApp**.
4. Publique e rode o teste de `roteiro-teste.md` com três a cinco pessoas.

## Páginas do MVP
- **Home** (/) — Mostrar em cinco segundos o que o projeto faz
- **Sobre** (/sobre) — Dar confiança mostrando quem faz e como trabalha
- **Catálogo** (/catalogo) — Mostrar o que se vende e quanto custa
